# Soft Voting for Policy-Aware Private Data Synthesis

Experiment code, fixed configurations, numerical results, and figures for the
current paper draft. The 30 unique experimental panels are supplied separately
as PNG and PDF; repeated panels in the paper use the same asset.

Paper draft: [PDF](_EDBT__Soft_Voting_for_Policy_Aware_Private_Data_Synthesis.pdf).

## Structure

```text
code/                          Synthesis, metrics, analyses, plotting, and tests
data/                          Adult/Bank inputs and preprocessing metadata
experiments/configurations/    Fixed settings for each paper experiment
experiments/run_paper_experiments.py
results/                       Figure tables and paired statistical results
results/raw/                   Seed-level records and synthetic outputs
figures/                       Individual PNG/PDF figures and paper-name mapping
scripts/                       Data preparation, tests, validation, figure replay
environment.json               Recorded software environment
checksums.json                 File-integrity manifest
outputs/                       Newly executed experiments and figure exports
```

## Setup

Use Python 3.11. Install the recorded dependencies and PyTorch:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121
```

For Linux/macOS, activate with `source .venv/bin/activate`. Fresh synthesis runs
require a compatible NVIDIA GPU and CUDA-enabled PyTorch. Saved-result figure
replay and the sensitivity measurements run on CPU. Runtime measurements are
hardware-dependent.

## Reproduce the paper figures

Run commands from the repository root:

```powershell
python scripts/validate_repository.py
python scripts/run_tests.py
python scripts/reproduce_figures.py --output outputs/paper_figures
```

The plotting command uses the supplied numerical tables and writes all 30 panels
as PNG and PDF, with figure-source tables and an export manifest. It does not
execute synthesis or overwrite `figures/`. Choose a new output directory for
each replay. `figures/figure_index.csv` maps the paper's original filenames to
the repository's descriptive filenames.

## Run the experiments

Inspect the fixed configuration count, then execute a family:

```powershell
python experiments/run_paper_experiments.py --family all --list
python experiments/run_paper_experiments.py --family crossover --execute --run-id crossover_run --workers 2
python experiments/run_paper_experiments.py --family sensitivity --execute --run-id sensitivity_run
```

Every run uses a separate workspace under `outputs/runs/<run-id>/`. Existing
run identifiers are rejected. Workers use the supplied settings, paired seeds,
and repetition counts without loading the archived result cache. The run
manifest records executed configurations, source hashes, completion, and errors.

## Data

Adult and Bank use five modeled columns, including the label. Their UCI input
archives, preprocessing, and fixed split seed are defined in `code/data.py`.
Source URLs and archive checksums are in `data/manifest.json`. Private training
sizes are 26,048 for Adult and 27,126 for Bank. XOR data are generated by code.

Processed benchmark inputs are included locally. If missing, prepare and check
the original inputs with:

```powershell
python scripts/prepare_data.py
```

Large benchmark archives and seed-level JSON/NPZ outputs are excluded from ordinary
Git tracking. They are present in this local folder. Figure replay requires only
the tracked numerical tables. Fresh synthesis requires the processed inputs,
which the preparation command recreates. `results/raw/index.csv` records the
stored output paths and checksums. To check all locally stored outputs:

```powershell
python scripts/validate_repository.py --raw
```

## Settings, metrics, and uncertainty

- Crossover uses `tau = 0.015, 0.03, 0.06`, one Hard baseline, 17 common budgets
  from `1e-5` through `1`, and twelve paired runs.
- Equal-noise uses `q = 0.1806440668446314` for Adult/Bank. XOR3 uses
  `(tau, theta) = (0.01, 1), (0.02, 2), (0.04, 4)` and
  `q = 0.9453064264076342`. The equal-q control is within XOR3, not across all
  three datasets. Actual reach and calibration settings are in the saved JSONs.
- Temperature sweeps use twenty positive temperatures and the Hard reference,
  with six paired runs. Mechanism decomposition separately uses temperatures
  `0.045`, `0.065`, and `0.02` for Adult, Bank, and XOR3.
- Direct sensitivity evaluates 1,320 configurations over 22 temperatures.
  The last three tail temperatures, `20, 50, 100`, satisfy the 1% of `sqrt(2)`
  criterion for both the measured sensitivity and bound.
- Adult/Bank fidelity is mean pairwise marginal L1 error. XOR3 fidelity is the
  16-cell joint L1 error of the three thresholded inputs and parity label.
- Relative error reduction is `100*(hard_error-soft_error)/hard_error` for
  each paired run, then averaged. The zero reference represents Hard. Intervals
  are pointwise 95% Student-t intervals.
- The extra experiments use twelve paired confirmation runs. All 680 primary
  contrasts are retained for the study-wide Holm correction, including contrasts
  not displayed in the three selected panels. Fixed public choices are recorded
  in the confirmation configuration; new private errors are not used for tuning.

The 45 unit tests and saved-table figure replay were verified locally. Full
CUDA-backed experiment reruns are separate from saved-result replay.
